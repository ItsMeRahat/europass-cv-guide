# 📄 Easy Guide to Creating a Europass CV

An interactive, step-by-step guide to creating a free **Europass CV** from Bangladesh — no scrolling needed.

## Features
- Single-screen, step-by-step design
- Navigation: buttons, dots, keyboard arrows (← →) and swipe on mobile
- Documents checklist (ticks are remembered in the browser)
- Light / dark theme, mobile-friendly

## Live Preview (GitHub Pages)
